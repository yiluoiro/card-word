Hello Theme

这是一个 static 运行时插件示例：没有后端进程，只由核心的 /assets/plugins/<uid>/ 提供文件。

它演示了什么

  • manifest.json 的最小合法结构（schema / uid / version / kind）
  • runtime.type = "static" 与 static.index
  • 权限白名单：只声明 theme.override
  • 可在后台渲染的 settings 配置字段

打包与安装

zip -r hello-theme.zip manifest.json index.html theme.css
go run ./cmd/cardword-sign keygen --out ./keys
go run ./cmd/cardword-sign sign --key ./keys/ed25519.key --in hello-theme.zip

然后在后台「应用商城 → 上传安装」提交 ZIP 与签名，核对权限后启用。

想接入真实业务？把 runtime.type 改成 external，声明 http.outbound，然后按 docs/PLUGIN_SDK.md 暴露 /payment/create、/hook 与 /healthz。
