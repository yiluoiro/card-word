# 商品与收款配置

在 `/admin/payments` 配置本店自己的收款服务。支持支付宝官方 RSA2、微信 API v3 Native 公钥模式、易支付 V2 RSA / V1 MD5，以及人工收款。公网回调使用 `CARDWORD_BASE_URL`，线上应配置为实际 HTTPS 域名。

支付凭据加密保存。未填写并启用服务商前不会自动开通支付；没有默认收款账号。人工收款需由有权限的管理员确认到账后发货，退款操作仅记录系统状态，实际退款需在支付服务商完成。

商品编辑支持多规格、独立价格与规格库存。首次添加规格前先处理原商品的未结订单。商品、卡密、订单、优惠码和买家账号均属于此单店铺实例。

公告支持草稿、发布和撤下，可面向全部访客、未登录访客或登录买家展示，并选择弹窗或静默。店铺名称、联系方式、SEO 和首页模板可在后台分别配置。

本版本不设平台代收、24 小时资金冻结、提现、保证金或平台仲裁流程。每家店主自行配置并管理支付账户。
