# 宝塔面板部署（免终端操作）

本包使用宝塔的「网站 → Go 项目」，由面板管理启动、停止和域名映射。需要已有该功能的宝塔 Linux 面板及 Nginx。程序已经编译，内含页面和 SQLite，不需要安装 Go、PHP、Node.js 或 MySQL。

## 1. 上传解压

按服务器架构选择包：x86_64 用 amd64，ARM64 用 arm64。

在宝塔「文件」中上传并解压到 `/www/server/`，得到 `/www/server/cardword/`。在该目录的「权限」中将所有者设为 `www` 并应用到子目录；确保目录可读写、程序 `cardword` 权限为 `755`。不要另建 PHP/静态站点公开这个目录。

## 2. 添加 Go 项目

打开「网站 → Go 项目 → 添加项目」，按下表填写：

| 项目 | 填写内容 |
| --- | --- |
| 项目执行文件 | `/www/server/cardword/cardword` |
| 项目名称 | `cardword` |
| 项目端口 | `8766`（不需要放行公网端口） |
| 执行命令 | `/bin/bash /www/server/cardword/start.sh https://你的域名` |
| 运行用户 | `www` |
| 开机启动 | 开启 |
| 绑定域名 | 你的域名，不带 `https://` |

执行命令填写整行，替换面板自动生成的命令；把“你的域名”换成实际域名。保存后，在项目设置中确认「外网映射」已开启，并在 SSL 中申请证书、开启 HTTPS。域名需先解析到这台服务器。

端口已占用时，例如改用 8767：将项目端口改为 `8767`，执行命令末尾追加 ` 8767`。一个实例只由一种方式启动，不要同时执行旧包的 install.sh。

## 3. 打开网站安装

浏览器访问 `https://你的域名/install`。在宝塔「文件」中打开 `/www/server/cardword/data/install-token.txt`，复制安装码到网页，然后填写站点名称和管理员账号密码。

安装完成后会进入后台登录，安装码自动删除，安装入口关闭。本店收款和邮件通知在后台另行配置。

## 更新和备份

在 Go 项目列表停止项目，通过文件管理打包整个 `/www/server/cardword/` 目录作为备份。升级时只替换程序 `cardword`，确认权限为 755 后启动项目。保留 `data/`，其中包含数据库、上传文件和加密密钥。备份下载到安全位置，不要放在网站公开目录。

如果当前已经使用旧包的 systemd 安装方式，请继续按旧包文档更新，不要把新包当作现有数据的迁移工具。

## 常见问题

- 启动失败：在项目日志查看原因；确认包与 CPU 架构一致、文件可执行、目录属于 www，执行命令中的路径正确。
- 域名打不开：确认 DNS、外网映射和证书配置；程序只监听本机，直接访问公网 IP:8766 不会打开。
- 没有 Go 项目入口：该流程依赖面板的 Go 项目功能，请先安装/启用该功能。
- 上传较大应用包被拒绝：若面板生成的代理限制上传大小，在项目 Nginx 配置的 server 内把已有 `client_max_body_size` 改为 `16m`，没有才添加，不要重复配置。

本包复用已通过应用与安装测试的程序。宝塔面板各版本界面可能略有差异，尚未在目标宝塔服务器实际部署验证。
